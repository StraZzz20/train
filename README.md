# Витрина туристских поездов

Одностраничный прототип витрины туристических поездов РЖД.

## Запуск локально

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. Сборка для продакшена: `npm run build`, предпросмотр: `npm run preview`.

## Решения

**Стек:** Vite + React — быстрая сборка, простой деплой на GitHub Pages / Vercel / Netlify без бэкенда. Данные загружаются из `public/trains.json` через fetch.

**UI:** карточки с фильтрами (регион, месяц, поиск), детальная страница по клику без роутера — достаточно для прототипа. Адаптивная сетка и типографика Manrope.
